Rubinite achievements: all 38, grouped by how you get them

100% route

If you are hunting the full set, the efficient order is:

  • First playthrough (illusion): grab all 7 talisman chests as the Monastery opens, collect Memories, beat every boss. Take Talismans? Nah. and True Hunter on the Beast.
  • Cleanup pass: replay the conditional kills (Bomb Disposal Expert, Plague It Cool, Out-Of-Body) via Recall Battle — the Illusion variant lets you take damage without failing the run.
  • Real World: True Difficulty comes free; the four exclusive bosses add their own kills. Do Finders Keepers? here if you missed chests.
  • Last: Fully Fledged / Fulfilling A Wish once the skill tree is bought out with Blood Dust — the Greed talisman and the Main Hall chest speed this up.

Frequently asked

How many achievements are there?

38 on Steam. The conditional kills are the only ones that need planning.

Hardest achievement?

Bomb Disposal Expert (Gravekeeper, no pods) and Out-Of-Body (Ghost, no self-harm corpses) — both are pure execution checks.

Is there a missable achievement?

Yes — You Dare Use My Own Weapons Against Me, Ruby? needs Roy's Daggers, which only drop after beating Roy, so it can only be done in a later Roy fight.
